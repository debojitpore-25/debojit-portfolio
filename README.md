# Personal Portfolio

A modern, responsive portfolio website built to showcase my projects, technical skills, education, and development journey.

## Overview

This portfolio serves as a central place to explore my work, learn about my technical interests, and get an overview of the projects and technologies I have worked with.

The website focuses on a clean interface, responsive design, smooth interactions, and a straightforward presentation of information.

* Fully responsive design across desktop, tablet, and mobile devices
* Clean and modern user interface
* Interactive sections and smooth transitions
* Dedicated project showcase
* Technical skills and technology stack

* Contact and social links
* Performance-conscious and maintainable structure
